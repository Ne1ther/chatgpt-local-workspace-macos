# macOS 1.5 / 核心 2.4.1 移植记录

基于现有 macOS 移植，纳入上游 [d8a4976（2.4.0）](https://github.com/CSL19980820/chatgpt-local-workspace/commit/d8a4976999b00c230b11486e524188c222142360) 与 [f2ab383（2.4.1）](https://github.com/CSL19980820/chatgpt-local-workspace/commit/f2ab3834a5fe77d52de6663c79a06d48004ddbaa) 的适用改进。核对日期：2026-10-17。本文记录 1.5 阶段的移植与历史验证；当前源码为 1.6.0，新增能力见 [1.6 记录](LOCAL-CAPABILITIES-1.6.md)。

## 后端

- 公开工具数 28 → 23。`poll_command`、`stop_command`、`list_commands`、`read_workspace_activity`、`file_info` 仍可调用，并返回替代用法。
- `read_command` 支持等待新输出；游标页和尾部读取只复制需要的区间。默认不重复附加 `full_output`，显式请求时仍可取得。
- 保留 zsh/Bash/sh、POSIX 进程树停止、真实 Shell 路径、大小写敏感路径规则与 macOS 状态加密。
- Codex 对话和回合元数据、追踪 ID、调用及已应用修改的行数统计；对话绑定只在改变时写入。
- 状态观察可在顺序执行线程忙碌时返回。原生状态接口继续只传输必要元数据，省去正文和输出。
- 独立保存有界的加密验证证据，清空可见日志和重启不会主动删除计划、对话、恢复记录或尚在保留范围内的证据。
- 组件清单用于区分已启动版本和磁盘版本；官方 Tunnel 0.0.16 下载经过 SHA-256 核对。重复 INFO 事件按上游精确名单折叠，告警、错误及未知信息保留。

不采用上游的启动时历史清空策略。此移植也没有将现有命令机制改为可跨后端退出恢复的独立任务调度器；后端退出后不应重试启动一个身份不明的旧命令。

## 原生界面与动效

- 主导航固定，项目列表独立滚动；连接概览展示实际状态、三段工作流程与最近操作。
- 图标保留选定的交织轮廓，采用暖白底、石墨色主体与蓝色终端下划线，按原生安全边距打包。
- 1.5.1 菜单栏保留系统按钮槽位，图像改为 20 pt、绘制目标 18 pt；蓝色下划线扩大至原生 10×2 pt，向左延伸到主体下方。仅真实工作且菜单栏可见时，Core Animation 移动一层蓝色信号，不逐帧重绘图标或执行 SwiftUI 计时器。
- 主界面用原生符号反馈执行位置，不采用跑马灯。减少动态效果、页面不可见或空闲时停止循环。
- 工作台保留单个临时 WebView，原生导航与网页导航不重复；隐藏时停止网页轮询和运行计时，恢复时立即同步。
- 工作台采用上游就地展开、回合分组、搜索筛选、可调检查器；只打包 49 枚 Phosphor Duotone 矢量图形，附带 MIT 原文，无 CDN。

## 验证

构建入口：`scripts/build_preview.sh`。已安装应用与本地 Preview 的包标识、配置空间分开；Preview 可按原有机制引用已保存连接，密钥仍保留在钥匙串。

- `scripts/build_preview.sh` 完成原生 Release 构建、后端发布、图标打包及正常包和 Preview 的签名校验；未覆盖 `/Applications` 中的安装版。
- `npm test`：25 项，24 通过、1 项 Windows 专用测试跳过、0 失败。覆盖 23 个公开工具、5 个旧工具、新旧协议、文件及命令隔离、停止进程树、超时、历史重开、加密保护、请求去重、游标等待、状态并发读取和清空日志后保留证据。
- 浏览器 UI 回归 18 项通过，含 640–1920 宽度、浅深色、就地详情、检查器、搜索、清空确认，以及原生模式隐藏时暂停轮询和计时。
- 先前开发记录包含 ChatGPT 网页经官方 Tunnel 的只读状态和文件调用，以及通过同一命令会话等待输出的短命令检查。这不等于长时间运行或网页关闭后模型续接的验收；私人对话链接和本机采样不随源码发布。
- ad-hoc 预览重建后，系统可能重新请求受保护文件夹权限；应由用户通过系统提示处理。新版工具参数也需要在宿主刷新工具定义后再验证。

以上没有验证十几个小时的任务恢复、网页关闭后的模型续接、Intel 真机、减少动态效果的实机切换，或全局菜单栏弹窗的逐项 UI 操作。编译和图层启停日志不等同于这些边界已完成验收。
