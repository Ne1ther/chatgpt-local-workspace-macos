# macOS 1.6：本地能力、可读性与自动建议

macOS 1.6.0 沿用 ChatGPT 网页 → 已注册 MCP App → Secure MCP Tunnel → Mac 的用法。原生应用版本 1.6.0，共享核心仍标记上游 2.4.1，公开工具仍为 23 个。

## 本地访问

侧栏“本地能力”提供目录选择、读取检查、按需读写检查和结果复制。检查由实际 MCP 后端执行，不用前端的 `isWritableFile` 推断权限。

- 读取检查只尝试枚举一个目录项，不递归扫描，不读取文件正文。
- 读写检查通过随机名称与 `CreateNew` 创建临时文件，写入后删除；原文件不变。清理失败会返回具体临时文件位置，不能报告全部通过。
- 结果带检查时间、解析后的实际目录和范围说明。重建连接、切换目录或开始新检查时清除旧结果。
- 受保护目录依然需要 macOS 授权；提供“文件与文件夹”设置入口。工作区用于组织操作，不是目录授权沙箱；当前 MCP 仍使用当前用户实际可访问的范围。
- 修正路径解析吞掉权限错误的行为。权限拒绝、路径不存在、输入错误分别报告，工具回执附带下一步；工作台详情同步展示恢复步骤。

## 长命令

`exec_command.timeout_seconds` 默认仍为 300 秒，可显式指定 1–86400 秒。返回实际超时预算和 `deadline_at`，现代任务返回覆盖运行预算的 TTL。通过相同 `session_id` 读取输出，停止仍清理本命令进程树。

支持 24 小时的预算不表示完成了 24 小时实测。后端需要持续运行；跨后端重启的命令恢复仍未实现。

## 可读性与简化

- 概览用“本地工作区”表达用途，主要操作改为进入工作台，停止连接保留在明确的菜单操作中。
- 修正侧栏选中项文字与背景同色；关键状态和说明使用可读的正文/说明字号。
- 连接诊断拆成逐项状态和运行组件版本，完整文本折叠保留。
- 去掉主界面的持续符号脉冲，运行信号保留在顶部菜单栏。
- 启动只检查凭据是否存在，真正读取密钥延迟至主动连接；读取与保存凭据在后台执行。取消后以连接代次丢弃迟到结果，避免意外重连。保存已有配置不为此读取密钥。离线预览可完全跳过凭据加载。
- Preview 构建在编译前检查旧预览是否正在运行，避免白做一次完整构建后才拒绝替换。

“建议处理”是基于已有状态的自动归纳：状态陈旧、连接故障、尚无真实网页调用、近期权限拒绝、命令超时和临时文件清理失败。相同工具对相同位置的更新成功记录可以覆盖早先失败；其他目录的成功不会掩盖原错误。建议最多显示三项，不新增后台轮询、模型请求或自动命令重试。

以下为 1.6.0 开发阶段的验证记录，不代表已创建新的 GitHub Release。

- 原生 Release 和应用签名验证通过。
- `npm test`：27 项，26 通过，1 项 Windows 专用测试跳过，0 失败。包括原有 MCP/文件/命令/工作台回归和新增本地访问测试。
- 新增实际后端测试覆盖：只读不写入、写入后清理、原有字节保持、拒绝访问、缺失路径、符号链接、跨站/无令牌/错误令牌拒绝、24 小时预算、超预算拒绝、现代任务 TTL 与取消、结构化恢复步骤。
- Swift 模型测试覆盖建议生成、相同路径恢复、不同路径不能掩盖错误、临时文件清理失败优先级与报告解码。
- 使用实际 `WorkspaceStore` 和慢速模拟凭据提供者验证：凭据 I/O 不在主线程，主界面执行器可以继续处理任务，取消后的迟到结果不会启动连接或提交旧配置。
- 本地能力与诊断布局曾用固定示例离线渲染；此类布局图不作为当前权限或连接状态的证据。

系统权限面板的实际点击、当前签名对“文稿”等受保护目录的访问、ChatGPT 网页新回合以及长达 24 小时的运行需要分别实测，不能用本地集成测试代替。

新签名读取已有密钥时仍需系统确认；后台化只解决窗口阻塞，不绕过系统授权。
