# 磁盘占用与清理

项目里的 .NET SDK、Node 依赖、Swift/.NET 编译缓存用于开发。构建后的 App 自带后端运行时和 Tunnel，可独立运行；开发目录和本机磁盘占用不代表安装包体积。

构建、测试完成后运行：

```sh
npm run clean:macos -- --dry-run  # 先列出目标
npm run clean:macos              # 删除可重新生成的开发目录
```

命令只处理当前项目的 `.tools/`、`node_modules/`、`macos/.build/`、`macos/backend/bin/` 和 `macos/backend/obj/`。清理前检查路径和文件占用；遇到符号链接、无法检查占用或发现目录正在使用时拒绝清理。打包好的 App、源码、Git、项目外数据和钥匙串不在清理范围。清理与编译不要同时运行；文件占用检查不能替代两个并发操作之间的互斥锁。

此命令使用 Node 内置模块，删掉 `node_modules` 后仍可运行。下次构建由原构建脚本重新下载 SDK、Tunnel 和前端依赖，首次重编译需要网络并会再次产生开发缓存。验证解压成功后，构建脚本不再保留 Tunnel 下载 ZIP。

## App 自身保存什么

| 内容 | 保存位置与保留方式 |
| --- | --- |
| 对话归组、计划、近期操作、撤销记录、请求去重表 | `~/Library/Application Support/LocalWorkspacePlugin/state-v1/`，加密状态文件。它们是有效记录，不作为垃圾清理。 |
| 最近操作与验证证据 | 各保留最近 100 条。文件直接修改的撤销记录最多 100 次、48 MiB 原始前后内容；加密前的 JSON/Base64 会有额外体积。 |
| 对话、计划、请求去重表 | 分别限制为 200、500、10,000 项；到达上限会拒绝新增，不静默删除旧记录。状态保存另有单文件 96 MiB 明文大小限制，达到限制会报错，不自动扩容或抹掉历史。 |
| 原生连接日志、图片预览 | 主要在内存中。原生日志最多 2,000 条、每条截断到 16,000 字符；图片缓存预算 32 MiB / 100 张。退出后不恢复图片缓存。 |
| 内嵌工作台网页 | 使用非持久 WebKit 数据存储，停止连接时释放会话。系统仍可能留下 WebKit/网络组件缓存，实际大小因运行情况而异。 |
| Tunnel 会话与本地自检 | 系统临时目录下的 `local-workspace-session-*`、`local-workspace-check-*`。正常停止或退出时删除本次目录；崩溃、强制退出或删除失败仍可能残留，目前没有启动时扫描清除其他会话目录的机制。 |
| 显示偏好、连接凭据 | 少量 UserDefaults 与钥匙串条目，和 App、开发缓存分开保留。 |
| Git 审阅基准 | 工作项目自己的 `.git` 私有引用和对象。随审阅内容增长，不属于可任意删除的临时缓存；清理命令不会运行 Git GC 或删除这些引用。 |

App 自身的记录有数量或大小限制，但这不限制用户通过 Shell 运行的程序；训练输出、下载文件和命令主动写出的日志仍由相应项目管理。
